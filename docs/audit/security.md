Scope: `apps/api` (all modules), plus a read-only review of `apps/web` and `apps/admin`. Every check below is enforced by a test in `apps/api/test/security/` unless the row says otherwise. Run them with `pnpm --filter @giftpop/api test -- test/security`.

## CSRF reasoning

The staff session is a cookie, so CSRF matters. Four layers cover it:

1. **SameSite=Lax**: browsers do not send the cookie on cross-site POST, PUT, PATCH or DELETE. No staff `GET` changes state (the route table in `admin-routes.test.ts` lists every method; mutating staff routes are POST, PUT, PATCH, DELETE). Login and logout are POSTs.
2. **Content type**: `express.json` is the only body parser, so a cross-site HTML form (`urlencoded`, `multipart`, `text/plain`) arrives with an empty body and fails validation. Multipart is only read on the asset and proof routes, after `requireStaff()` for assets.
3. **CORS allowlist**: a cross-origin `fetch` with `Content-Type: application/json` needs a preflight, and only the origins in `CORS_ORIGINS` pass it (no wildcard, credentials only for listed origins).
4. **Origin check** (S4): the store and the admin are the same site, so Lax does not separate them, and the store is in the allowlist. `requireStaff` therefore also refuses a state-changing request whose `Origin` is not `ADMIN_ORIGIN`. Browsers always send `Origin` on those methods; a request without one (server to server, curl) is not a browser CSRF. Because both Next apps proxy `/api/*`, the browser's `Origin` is the app's own origin, which is `ADMIN_ORIGIN` for the admin.

**Deploy note:** `ADMIN_ORIGIN` must equal the exact origin staff use (scheme, host and port, no path). A preview URL that differs from it will get 403 on every staff write.

**Login and logout:** login needs no CSRF token (it has no session to hijack; a forged login only signs the victim in as the attacker, and a cross-site POST with JSON is blocked by CORS and the content type rule). Logout from a foreign origin carries no cookie under Lax, so it cannot sign a staff member out.
